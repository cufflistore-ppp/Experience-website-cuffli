PENGATURAN WAJIB DI FIREBASE CONSOLE:
1. Authentication > Sign-in method > aktifkan Google.
2. Authentication > Settings > Authorized domains > tambahkan domain Vercel website.
3. Authentication > Settings > Authorized domains > pastikan elzikiijoki.firebaseapp.com tersedia.
4. Google Cloud Console > APIs & Services > Credentials > pilih OAuth Web Client ID di atas.
5. Authorized JavaScript origins: tambahkan https://DOMAIN-WEBSITE-VERCEL
6. Pastikan Firebase Authentication menggunakan OAuth client yang sama.
7. Realtime Database > Rules: gunakan FIREBASE_RULES.json yang sesuai dengan struktur database.
8. Deploy semua file ZIP ini ke direktori yang sama.

Catatan:
- ej-auth.js adalah satu sumber konfigurasi dan login ELZKII JOKI.
- Login Google menggunakan Firebase Authentication (GoogleAuthProvider).
- Sesi login disimpan menggunakan LOCAL persistence agar tetap masuk saat pindah halaman/refresh.
- Pada browser Android yang memblokir popup, login otomatis mencoba alur redirect.
- OAuth Client ID bukan password rahasia, tetapi jangan pernah memasukkan service-account private key ke frontend.
