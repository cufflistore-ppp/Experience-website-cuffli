# NAILONG Tools Portal

Mock static website inspired by public tools portals.

## Features (UI only)
- Downloader category (Terabox, IG, TikTok, YT, Spotify) — mock
- Maker tools (BRAT, IQC, Fake cards, Quotes, etc.) — mock
- Utility tools (QR, Password, Hash, Calculator, etc.) — mock
- Vault & VVIP sections — mock
- File explorer with sample assets

## How to run
Just open `index.html` in any modern browser.
No build step, no backend required.

## Disclaimer
This is a frontend demo / educational mock only.
No real download, scraping, or generation services are implemented.
