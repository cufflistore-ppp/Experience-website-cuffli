========== SALIN SAMPAI SINI ==========


=== APA YANG DIAMANKAN ===

1) PANEL ADMIN (server-side)
   - settings, branding (logo/banner/QRIS), produk_images
     → HANYA 2 email admin yang boleh tulis
   - User biasa yang coba ubah lewat console/API → PERMISSION_DENIED

2) PRODUK
   - Baca: semua orang (katalog toko)
   - Tulis penuh (nama, harga, hapus, tambah): admin saja
   - User boleh update terbatas saat order (stok berkurang),
     asalkan nama/harga/kategori tidak berubah

3) ORDERS
   - Baca: user login (riwayat app tetap jalan)
   - Buat order baru: user, wajib uid sendiri + status "Menunggu"
   - User TIDAK bisa ubah status / harga / kode order orang lain
   - User boleh update order sendiri (linkTarget, catatan) tanpa ganti status/harga
   - Admin: full kontrol (ubah status, tolak, selesai, dll)

4) ORDER_FILES (hasil kirim admin: APK/link file)
   - Baca: user login (pembeli lihat hasil)
   - Tulis: admin saja

5) CHAT
   - Hanya pemilik chat (uid) atau admin
   - Orang lain tidak bisa buka chat user lain

6) FRONTEND
   - admin.html / admin-kelola.html tetap pakai requireAdmin()
   - Email selain 2 admin → ditolak di UI + di rules


=== TES CEPAT SETELAH PUBLISH ===
1. Login email biasa → buka admin.html → ditolak
2. Login email biasa → tidak bisa ubah produk/settings di Firebase
3. Login email biasa → order + upload bukti TF tetap bisa
4. Login admin → panel, ganti logo/QRIS, ubah status order → OK
5. User coba ubah status order jadi "Selesai" lewat API → DENIED
