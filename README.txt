2. Login/daftar belum aktif sampai Firebase Authentication dihubungkan di js/firebase.js dan js/auth.js.
3. Jangan publikasikan service-account JSON atau private key di folder website.
4. Panel admin harus dilindungi backend/Firebase Custom Claims dan Rules. Menyembunyikan halaman dengan JavaScript bukan pengamanan.
5. Pesanan WhatsApp hanya membuka chat admin; status order, pembayaran, upload produk, dan riwayat otomatis masih perlu backend/database.
